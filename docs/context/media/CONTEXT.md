# Media Context

This context names images and media surfaces in Odysseus.

## Language

**Gallery**:
The place to browse, manage, and reuse generated or imported media.
_Avoid_: Image folder, asset dump

**Image Editor**:
The place for changing images, including selection, masks, inpainting, and export.
_Avoid_: Gallery

**Generated Media**:
Media made by an AI model or Odysseus tool.
_Avoid_: Upload

**Media Asset**:
An image, audio, video, or other media item stored for reuse.
_Avoid_: Document

**Mask**:
The selected part of an image that an edit should affect.
_Avoid_: Layer

**Inpaint**:
Filling or changing part of an image using a mask.
_Avoid_: Full image generation

**Layer**:
One editable piece of an image composition.
_Avoid_: Image file
