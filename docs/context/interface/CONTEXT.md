# Interface Context

This context names common UI places in Odysseus.

## Language

**Sidebar**:
The always-available navigation area for main features and recent work.
_Avoid_: Menu

**Panel**:
A visible area of the interface for one feature or task.
_Avoid_: Page

**Library**:
A place to browse and manage saved items for one feature, such as documents, email, or WhatsApp.
_Avoid_: Dashboard

**Cockpit**:
A busy work area with several panels for checking and acting on related things.
_Avoid_: Dashboard, landing page

**Gallery**:
The media-specific library for images and visual media.
_Avoid_: Library when referring to the named media feature

**Modal**:
A focused overlay for a bounded task without leaving the workspace.
_Avoid_: Page

**Toast**:
A small temporary message that tells the user something happened.
_Avoid_: Alert dialog

**Tour**:
A guided set of hints that explains a feature.
_Avoid_: Documentation

**Empty State**:
The UI shown when a list, library, or feature has no items yet.
_Avoid_: Error state

**Mobile Step**:
One step of a larger workflow shown on a small screen.
_Avoid_: Responsive layout
