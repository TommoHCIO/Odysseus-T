# Knowledge Context

This context names long-term knowledge in Odysseus.

## Language

**Knowledge**:
The long-term place for useful things Odysseus should remember.
_Avoid_: Brain, Memory

**Knowledge Candidate**:
A suggested knowledge item that is not accepted yet.
_Avoid_: Knowledge, memory

**Curation**:
Checking, editing, accepting, or rejecting Knowledge Candidates.
_Avoid_: Automatic save

**Journal Event**:
A raw meaningful event written into the journal. It records history but is not the same as curated Knowledge.
_Avoid_: Knowledge, product event

**Recall**:
Finding useful information from Knowledge.
_Avoid_: Search for every way to find saved knowledge

**Obsidian Vault**:
The Markdown folder structure where Knowledge is stored.
_Avoid_: Brain, Memory store

**Knowledge Note**:
A Markdown note in the Obsidian Vault that holds saved Knowledge.
_Avoid_: Chat message, document by default

**Knowledge Graph**:
A visual map of Knowledge notes and their links.
_Avoid_: Search results

**Brain**:
The old visible knowledge feature name. Use it only for old compatibility paths.
_Avoid_: Main knowledge store

**Memory**:
An old compatibility word for remembered knowledge. New product language should say Knowledge.
_Avoid_: Brain, main knowledge store
