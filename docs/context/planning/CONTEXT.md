# Planning Context

This context names notes, tasks, reminders, schedules, and calendar items.

## Language

**Note**:
A quick user-written record. It is not Knowledge, a task, or a document by default.
_Avoid_: Knowledge, document

**Checklist**:
A note or task list made of items that can be checked off.
_Avoid_: Calendar event

**Task**:
A trackable piece of work that can be completed, scheduled, or assigned to an agent workflow.
_Avoid_: Note, reminder

**Reminder**:
A prompt that brings something back to the user's attention.
_Avoid_: Task

**Scheduled Task**:
A task set to run at a future time or on a repeating schedule.
_Avoid_: Reminder

**Calendar Event**:
A time-bounded item on a calendar.
_Avoid_: Task, reminder, system event

**Calendar**:
A collection of calendar events.
_Avoid_: Task list

**CalDAV Sync**:
Calendar syncing with an outside CalDAV provider.
_Avoid_: Import

**Notification Channel**:
The place Odysseus sends reminders or alerts, such as browser, email, or ntfy.
_Avoid_: Provider
