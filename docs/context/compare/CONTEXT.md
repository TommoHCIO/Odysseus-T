# Compare Context

This context names side-by-side model testing in Odysseus.

## Language

**Compare**:
The Odysseus feature for testing model answers side by side.
_Avoid_: Research, chat

**Comparison Run**:
One model comparison session for a prompt or task.
_Avoid_: Chat session

**Blind Test**:
A comparison where model names are hidden until after judging.
_Avoid_: Model picker

**Candidate Answer**:
One answer being compared against others.
_Avoid_: Final answer

**Vote**:
A user choice about which candidate answer is better.
_Avoid_: Score

**Combined Answer**:
An answer made by using the best parts of multiple candidate answers.
_Avoid_: Report
