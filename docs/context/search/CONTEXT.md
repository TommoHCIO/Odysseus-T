# Search Context

This context names finding information and using sources.

## Language

**Search**:
Looking for information in web sources, local stores, documents, communications, or Knowledge.
_Avoid_: Research

**Search Query**:
The words or filters used to search.
_Avoid_: Research job

**Web Search**:
Search over internet sources.
_Avoid_: Deep Research

**Local Search**:
Search over data stored in Odysseus.
_Avoid_: Web search

**Index**:
A searchable version of source content.
_Avoid_: Archive

**Full-Text Search**:
Search over words in stored text.
_Avoid_: Vector search

**Vector Search**:
Search by meaning using embeddings.
_Avoid_: Full-text search

**Ranking**:
Ordering search results by likely usefulness.
_Avoid_: Filtering

**Retrieval**:
Finding relevant records or passages before an answer, summary, or action.
_Avoid_: Recall unless searching Knowledge

**Evidence**:
Source material that can be traced back to where it came from.
_Avoid_: Context, unstated background

**Summary**:
A shorter explanation of existing material. It should not add unsupported claims.
_Avoid_: Report, research output
