# Documents Context

This context names documents and writing places in Odysseus.

## Language

**Document**:
A user-owned editable file or writing place. AI can help, but the user owns the writing.
_Avoid_: Artifact, attachment

**Document Library**:
The place to browse, open, import, export, and manage documents.
_Avoid_: File browser, uploads

**Editor**:
The focused place where a document is written or changed.
_Avoid_: Composer, canvas

**Document Version**:
A saved earlier state of a document.
_Avoid_: Backup

**Suggestion**:
An AI-proposed document change that the user can accept, reject, or edit.
_Avoid_: Automatic edit

**Annotation**:
A note or mark attached to part of a document.
_Avoid_: Document content

**Attachment**:
A file attached to another workflow, such as Email or Documents. It is not automatically an editable document.
_Avoid_: Document
